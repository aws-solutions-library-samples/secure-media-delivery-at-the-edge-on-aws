# Revocation Dashboard — Standalone

The standalone `dashboard.html` provides a full-featured revocation management interface, including a **Bedrock Prompt Editor** for customizing the AI-powered auto-revocation analysis.

## Features

### Revocation Overview
- **Total / Auto / Manual** revoked session counts
- Live table of all revoked sessions with session ID, reason, and timestamp
- Auto-refreshes every 15 seconds

### Bedrock Prompt Editor

When the optional `CTASecureMediaAutoRevocation` stack is deployed, the dashboard shows an editable textarea containing the Bedrock analysis prompt. This prompt controls how Amazon Bedrock Nova Lite/Pro evaluates session metrics to decide whether to auto-revoke a token.

**How it works:**
1. The prompt is stored in AWS Systems Manager Parameter Store
2. The Kinesis analyzer Lambda reads it before each Bedrock invocation
3. Editing the prompt here takes effect on the next analysis cycle (~1 minute cache)

**Prompt API:**
- `GET /prompt` — reads the current prompt from SSM
- `PUT /prompt` — updates the prompt in SSM

The prompt editor is only visible when `PROMPT_CONFIG` is set (i.e., the auto-revocation stack is deployed and its API endpoint is configured).

## Deployment

The dashboard is deployed automatically alongside the demo websites when `enableDemo=true`:

```bash
npx cdk deploy --all -c enableDemo=true
```

It's served at: `https://<distribution>/website/dashboard.html`

## Relationship to Embedded Dashboards

The three demo pages (`index-path.html`, `index-header.html`, `index-hybrid.html`) each have an **embedded** revocation dashboard section showing the sessions table and stats. However, they do **not** include the Bedrock prompt editor — that feature is only available in this standalone dashboard.

## Configuration

The dashboard loads two config files at runtime:

- `config.js` — provides `CTA_CONFIG.apiEndpoint` (generated by CDK at deploy time)
- `prompt-config.js` — provides `PROMPT_CONFIG.apiEndpoint` for the auto-revocation Prompt API (deployed by the `CTASecureMediaAutoRevocation` stack)
