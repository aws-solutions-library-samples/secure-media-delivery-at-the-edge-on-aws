How the Hybrid Flow Works

Combines the simplicity of CMS-generated path URLs with the elegance of header-based renewal. The CloudFront Function always strips stale path tokens, regardless of which delivery method is used for authentication.

  1. Initial playback (path): CMS or API returns a signed URL /{TOKEN}/video/stream.m3u8 — player loads it directly
  2. CloudFront validates the path token, strips it, forwards /video/stream.m3u8 to origin
  3. Before expiry: player calls POST /token and gets a fresh token (no signed URL needed)
  4. Renewed requests: player sends CTA-Common-Access-Token header — the stale path token from the original URL is still present but gets stripped harmlessly
  5. CloudFront validates via header (takes priority), strips stale path segment, forwards clean path to origin
