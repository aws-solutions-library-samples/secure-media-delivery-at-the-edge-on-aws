How Header-Only Flow Works

The player attaches the CWT token as an HTTP header on every request. Renewal simply swaps the header value — no URL changes needed.

  1. Web app calls POST /token to get a CWT token (no signed URL needed)
  2. Player configures xhrSetup to attach CTA-Common-Access-Token: <token> on every request
  3. CloudFront Function reads the header, validates the COSE MAC0 token, and forwards to origin
  4. Before expiry, the app calls POST /token again and updates the header value — zero playback interruption
