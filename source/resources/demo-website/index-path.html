How Token Renewal Works

The CTA-5007-B flow uses path-based tokens with automatic client-side renewal, ensuring uninterrupted playback across token lifetimes.

  1. Initial request embeds a CWT token in the URL path: /{TOKEN}/video/stream.m3u8
  2. CloudFront Function validates the COSE MAC0 token, strips it from the path, and forwards to origin
  3. Before the token expires, the player requests a fresh token from the API (Lambda + Secrets Manager)
  4. The player swaps the old path token for the new one — playback continues seamlessly
